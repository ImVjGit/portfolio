How it works:

  • Page starts with a boot animation (progress bar + loading messages)
  • After boot, you see a terminal prompt — type help to see all commands
  • Each command (about, skills, etc.) prints content inline like a terminal
  • Skills shown as ASCII bar charts, projects as file listings
  • CRT scan lines overlay, green phosphor glow, occasional flicker
  • Clear readable monospace font (JetBrains Mono or IBM Plex Mono)
